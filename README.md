# Personal Portfolio Website

A modern and responsive personal portfolio website created using HTML,
CSS and JavaScript.

## 🚀 Project Overview

This project was developed as a beginner-level Web Development project
to create a professional online portfolio.

The website showcases:

- Personal introduction
- About section
- Technical skills
- Projects
- Education
- Contact information
- Social media profiles

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts
- Git
- GitHub

## ✨ Features

- Fully responsive design
- Mobile navigation menu
- Typing animation
- Smooth scrolling
- Scroll reveal animations
- Contact form validation
- Interactive project cards
- Responsive skill cards
- Modern dark developer UI
- GitHub Pages compatible
